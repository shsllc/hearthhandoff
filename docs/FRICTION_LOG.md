Format per the hackathon's optional friction-log bonus: task, what we expected, what actually happened, impact, and workaround. Newest entries at the bottom.

| 1 | 2026-10-05 | Verify webhook signatures using the official sample | The sample's webhook route uses the documented HMAC `X-Signature` | The sample checks `Authorization: Bearer ${RING_WEBHOOK_SECRET}`. The API reference specifies `X-Signature: sha256=<hex HMAC-SHA256 of raw body>` | A developer copying the canonical starter would accept unsigned or spoofed webhooks, or reject real ones | Implemented the API-reference algorithm. A real doorbell press fails validation and falls into "generic" normalization | Doorbell presses, the most useful caretaking signal, are mis-parsed by the starter | Wrote our own parser from the API reference |
| 3 | 2026-10-05 | Follow doc links from the sample README | Links resolve | `docs/ring/notifications.html` and `docs/ring/authentication.html` return 404. The content now lives as anchors inside the single `api-documentation.html` (about 1 MB) | Slowed discovery. The WebFetch-style tools we used summarized the giant page lossily and missed the payload examples | Downloaded the page and read the sections directly |
